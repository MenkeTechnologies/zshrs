## Bugs uncovered + fixed during the audit

1. **langinfo[CODESET] returned "US-ASCII"** — locale not initialized.
   Fixed: `unsafe { libc::setlocale(LC_ALL, c"".as_ptr()) }` in
   `ShellExecutor::new` (`src/vm_helper.rs`).
2. **`int(2.7)` returned "2."** — Float result with trailing dot
   instead of Integer-typed result. Fixed: split `always_int`
   (int/floor/ceil/trunc) from `int_preserving` (abs/min/max) in
   `src/ported/math.rs`. New `float()` math fn added.
3. **WATCHFMT was empty by default** — zsh ships
   `"%n has %a %l from %m."` per Src/Modules/watch.c:60. Fixed:
   seeded via `setsparam` in `src/ported/modules/watch.rs`.
4. **zstat -A populated assoc, not array** — `-A` should be
   indexed (values in field-table order), `-H` is the assoc form.
   Fixed: split paths in `builtin_zstat`.
5. **zparseopts dropped the `=` separator** — `--name=foo` should
   capture value as `=foo`, not `foo`. Direct port of zsh's
   bin_zparseopts value-collection (`src/ported/modules/zutil.rs`).
