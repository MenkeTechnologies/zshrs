# Snapshot of (rust_file, fn_name) pairs where the Rust port lands in
# a file whose C-counterpart basename doesn't contain the matching
# function definition. Format: `<rust_relpath>::<fn_name>`.
#
# Examples:
#   src/ported/utils.rs::printhhmmss
#     — C source has printhhmmss in jobs.c, not utils.c. Either move
#       to a jobs-area Rust file or accept the mismatch.
#   src/ported/utils.rs::getpid / mkdir / getenv / setenv / etc.
#     — these are libc wrappers, not zsh-specific. zsh's C source
#       references them without defining them; the file-grep finds
#       call-site occurrences. Listed here as exempt since they're
#       genuine system-call wrappers.
#
# Anything in this list is exempt from the file-mapping check.
# Anything NOT in this list AND in the wrong file fails the test.
#
# To shrink: move the fn to the right Rust file (matching its C
# basename), or rename to point at the actual C definition you're
# porting from. Then remove the line.
#
# Lines starting with `#` are comments. Blank lines ignored.
