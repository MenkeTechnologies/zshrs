# Snapshot of free `fn` names in src/ported/**.rs that have no
# matching function definition in zsh's upstream C source. Each line
# is one identifier — the test reads this file and treats anything in
# it as "exempt-for-now". Anything NOT in this file that appears as a
# free fn in src/ported/ AND has no C counterpart fails the test.
#
# Process to fix a violation: inline the body at every call site (or
# rename to match a real C function name), then remove the line from
# this file. The list shrinks as the port catches up to the freeze.
#
# To regenerate after intentional removals:
#   cargo test --test ported_fn_names_match_c -- --nocapture 2>&1 \
#     | grep "no C counterpart" \
#     | sed -E 's/.*fn ([a-zA-Z_][a-zA-Z_0-9]*).*/\1/' \
#     | sort -u > /tmp/new_violations.txt
#   then merge with the existing list, keeping the header.
#
# Lines starting with `#` are comments. Blank lines ignored.
