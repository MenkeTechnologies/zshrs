# git_parity_cases.txt — the `git` TAB-completion parity corpus.
#
# Run it, whole, with:
#
#   /opt/homebrew/bin/python3 scripts/comptab_parity.py \
#     --corpus scripts/git_parity_cases.txt --sequences tab1,tab2 \
#     --jobs 1 --key-budget 25 --dump <a ZSH-WRITTEN .zcompdump>
#
# One command-line prefix per line; `#` comments and blank lines are ignored
# (comptab_parity.py:2209-2210), and a line's TRAILING SPACES are part of the
# buffer — `git add ` completes an argument, `git add` completes the command
# name. Never put a comment on the same line as an entry.
#
# --dump IS NOT OPTIONAL. `resolve_dump` (comptab_parity.py:316-326) globs
# `~/.zpwr/local/.zcompdump*` and takes the first hit, which may be a dump
# written by ZSHRS. zshrs ports the core compsys functions natively and writes
# no autoload stub for them, so real zsh sourcing such a dump gets
# `_main_complete: command not found` and completes NOTHING — every cell scores
# TIMEOUT at any key budget, and `dump_health` does not catch it because
# `$#_comps` still reads ~51000. Precondition: `grep -c _main_complete <dump>`
# must be >= 1.
#
# PROVENANCE. Generated 2026-09-20 from `git help -a` (git 2.55.0) plus
# hand-written families, deduplicated in order:
#   * one argument-position cell per porcelain/ancillary subcommand,
#     minus the ones whose completer is slow, interactive or network-bound
#     (fetch/pull/push/clone/submodule/gui/gitk/send-email/p4/svn/gc/fsck/...)
#   * `git <sub> --` long-option listing for 50+ high-traffic subcommands
#   * nested subcommand tables: remote, stash, bisect, worktree, notes,
#     sparse-checkout, bundle, reflog, rerere, config, tag, branch
#   * `--opt=` value cells (format/pretty/date/diff-filter/strategy/color/
#     untracked-files/ignore-submodules/sort/cleanup/whitespace/...)
#   * positional and ref cells (`git checkout main -- `, `git diff main..`,
#     `git log HEAD`, `git reset --hard `, `git cat-file -p `, ...)
#   * global-option cells (`git -c `, `git -C `, `git --git-dir=`, `git -p `)
#
# Cells that contact a remote are deliberately ABSENT: they make both shells
# slow by the same amount, which turns into TIMEOUT noise rather than signal.
#
