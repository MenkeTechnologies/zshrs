>_METHOD

  • zshrs built from tag v0.13.3 in a clean checkout and snapshotted, so other work in the shared tree could not relink it mid-run.
  • Oracle: zsh 5.9.1, the closest tagged release to the 5.9.2 target, built from source. scripts/ztst_compsys.py ran the suite once with zsh as baseline and once with zshrs as the shell under test.
  • This zsh build could not load pcre or zsh/param/private, has no gdbm, and P01privileged needs root. Those 74 assertions are excluded from both sides.
  • TAB screens: scripts/comptab_parity.py, native mode, pinned zsh-written compdump.
  • Surface and daily-driver checks compare against the host zsh 5.9.2.
  • C port coverage is read from the published port report (generated 2026-10-01), not regenerated for this page.
  • The main, 2026-10-03 column re-runs the 7 files holding the 9 divergences through scripts/ztst_compsys.py --core with a debug build of main against a zsh 5.9.1 built from the zsh-5.9.1 tag; every other figure on this page is the v0.13.3 run.
