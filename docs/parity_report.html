>_METHOD

  • ztst, TAB screens, cargo parity, surface, fuzz and daily driver: zshrs built from main (git archive into a scratch directory, debug profile). The non---zsh fuzz legs and the C-port count are carried over, as labelled.
  • Oracle: zsh 5.9.2 built from the zsh-5.9.2 tag with --enable-unicode9. scripts/ztst_compsys.py ran the suite once with zsh as baseline and once with zshrs as the shell under test (--core for the non-Y files, default mode for Y01–Y03). The 5.9.2 tree holds no Y04–Y06.
  • This zsh build has no gdbm and cannot load zsh/param/private, and P01privileged needs root. Those assertions are excluded from both sides.
  • X04zlehighlight, invoked as zsh: the shell sends no startup terminal queries or OSC 7 (5.9.2 sends none), writes text attributes with explicit off bits and per-attribute off capabilities as 5.9.2 does, and keeps hex colours 24-bit unless zsh/nearcolor is loaded. These gates apply to a zsh drop-in (--zsh or argv[0] zsh); native zshrs keeps the development-tree behaviour.
  • TAB screens: scripts/comptab_parity.py --sequences tab1 --discover 300 --key-budget 30, native mode, a pinned zsh-written compdump, reference Homebrew zsh 5.9.2.
  • cargo parity: cargo test --test parity; the reference shell is the development-tree oracle build resolved by tests/parity/oracle.rs, which lacks the restricted option and the subshell job-control guard that 5.9.2 has, so main differs from that oracle in a few cases it matched before. Failures re-run alone with --test-threads=1.
  • Surface and fuzz checks compare against the host zsh 5.9.2 and the reference shells named in each table.
  • csh: parity-fuzz --shell csh --count 2000 --seed 1 --verify 2 and cargo test --test csh_parity, debug build, reference /bin/tcsh 6.21.00; one run each. The generator covers 28 statement kinds; a hand-written battery of 170 further constructs was also run against tcsh (stdout and exit status; job pids normalised).
  • C port coverage is read from the published port report (generated 2026-10-06), not regenerated for this page.
  • Daily driver: a pty harness started each shell with -i and the real ~/.zshrc, waited 30 s, then sourced a probe file and typed the burst and quote lines.
