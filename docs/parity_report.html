>_METHOD

  • ztst, surface and the divergence table: zshrs built from main at ea21689246 (git archive into a scratch directory, debug profile). TAB screens, cargo parity and the emulation fuzz: the v0.13.18 build, not re-run.
  • Oracle: zsh 5.9.2 built from the zsh-5.9.2 tag with --enable-unicode9. scripts/ztst_compsys.py ran the suite once with zsh as baseline and once with zshrs as the shell under test (--core for the non-Y files, default mode for Y01–Y03). The 5.9.2 tree holds no Y04–Y06.
  • This zsh build has no gdbm and cannot load zsh/param/private, and P01privileged needs root. Those assertions are excluded from both sides.
  • X04zlehighlight stalls under zshrs and is killed at 300 s; its 12 assertions count as missed.
  • TAB screens (v0.13.18): scripts/comptab_parity.py --sequences tab1 --discover 300 --key-budget 30, native mode, a pinned zsh-written compdump, reference Homebrew zsh 5.9.2.
  • cargo parity (v0.13.18): cargo test --test parity; the reference shell is the development-tree oracle build resolved by tests/parity/oracle.rs, which lacks the restricted option and the subshell job-control guard that 5.9.2 has, so main differs from that oracle in a few cases it matched before. Failures re-run alone with --test-threads=1.
  • Surface and fuzz checks compare against the host zsh 5.9.2 and the reference shells named in each table.
  • C port coverage is read from the published port report (generated 2026-10-06), not regenerated for this page.
  • Daily driver (v0.13.18): a pty harness started each shell with -i and the real ~/.zshrc, waited 30 s, then sourced a probe file and typed the burst and quote lines.
