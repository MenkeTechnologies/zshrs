The gate

scripts/compsys_regressions.py replays every checked-in fixture and exits non-zero if anything moved in either direction: a fixture that stopped diverging is as much a failure of the run as one that started. Controls are cells a fixture pins as agreeing — they are what make the fixture's variable the variable, and a control that starts diverging fails the run too.
